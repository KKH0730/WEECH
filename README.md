# 📺 위치 (WEECH)

유튜브를 **같이 보는 3D 라운지**. 코루라이브의 '객장' 구조를 참고했습니다.
벽에 걸린 TV 에서 실제 유튜브가 재생되고, 모두의 재생 위치가 자동으로 맞춰집니다.

```
node server.js      →   http://localhost:3000
```

three.js 를 `public/vendor/` 에 동봉했습니다. **CDN 없이 로컬에서 돌아갑니다.**
(서버 자체는 외부 패키지 0개 — three.js 는 브라우저용으로만 쓰입니다)

---

## 흐름

**로비** 에서 둘 중 하나를 고릅니다.

| | 입력 |
|---|---|
| **방 만들기** | 방 제목 · 유튜브 링크(영상·재생목록 여러 개 가능) |
| **방 참여하기** | 목록에서 고르기 또는 5자리 코드 — 누르면 바로 입장 |

**닉네임은 묻지 않습니다.** 들어오는 순간 서버가 `졸린 수달` 같은 이름을 지어 줍니다
(같은 방 안에서 겹치지 않게 고릅니다). 마음에 안 들면 왼쪽 **참여자** 목록에서
내 줄의 **✎** 를 눌러 바꿉니다 — 바꿀 수 있는 건 **자기 이름뿐**입니다.

링크는 `watch?v=`, `youtu.be/`, `/shorts/`, `/embed/`, 생 영상 ID 를 모두 인식합니다.
**재생목록 링크(`list=`)도 서버가 펼칩니다.**

| 종류 | 처리 |
|---|---|
| 일반 재생목록 `PL…` `OL…` `FL…` | InnerTube `/next` 로 곡 목록을 통째로 받습니다 (실패하면 공개 페이지 긁기) |
| **믹스 / 라디오** `RD…` | **펼치지 않고, 공유한 씨앗 영상 한 곡만** 담습니다 — 아래 참고 |
| 씨앗 영상 | 공유한 사람이 들려주려던 곡이므로 **맨 앞으로** 옮깁니다 |

### 믹스(`RD…`)를 펼치지 않는 이유

`RD` 로 시작하는 ID 는 고정된 재생목록이 아니라, 유튜브가 씨앗 영상을 기준으로
**호출할 때마다 새로 만들어내는 무한 라디오**입니다 (응답에 `isInfinite: true`).
같은 링크를 1초 간격으로 두 번 받아보면 25곡 중 자리까지 같은 곡이 **4곡뿐**이고,
로그인 여부에 따라 개인화되어 공유한 사람이 본 목록과도 다릅니다.

그래서 펼치면 **목록에 없던 영상이 섞이고 순서도 뒤죽박죽**이 됩니다.
순서를 지키려면 `PL…` 로 시작하는 진짜 재생목록 링크를 쓰세요.

최대 50곡. 재생목록과 개별 영상을 섞어 적어도 **적은 순서가 유지**됩니다.
제목은 재생목록 페이지에서 읽고 없으면 oembed 로 채웁니다 — **둘 다 API 키가 필요 없습니다.**

## 방 — 22m × 16m (352㎡), 천장 8.8m

| 벽 | 무엇이 걸려 있나 |
|---|---|
| **정면** | **12m 스크린**(81㎡) + 그 위에 **네온 간판**(9.0×0.7m) + 오른쪽에 세로로 긴 **재생목록 전광판**(2.8×6.0m) |
| **왼쪽** | 액자 13점 + **실버 · 골드 버튼** 2점 (높은 천장에 맞춰 위쪽에도 한 줄) |
| **뒤쪽 천장** | **영사기** — 스크린까지 14.8m 를 가로지르는 빔이 재생 중에 보입니다 |

### 자리 — 영화관 좌석 50석

1인용 의자만 줄줄이 놓고, **뒷줄로 갈수록 한 단씩 올립니다.** 소파와 테이블은 없습니다.

```
          ┌───── 스크린 ─────┐

     · · · · ·   통로   · · · · ·    1열   바닥
     · · · · ·   통로   · · · · ·    2열  +12cm
     · · · · ·   통로   · · · · ·    3열  +24cm
     · · · · ·   통로   · · · · ·    4열  +36cm
     · · · · ·   통로   · · · · ·    5열  +48cm
```

| | |
|---|---|
| 좌석 | **5줄 × 10석 = 50석** (정원 20명이 앉고도 남습니다) |
| 단 | 줄마다 **12cm** — `STEP` 과 같은 높이라 **그냥 걸어 올라갑니다** |
| 통로 | 가운데 2.5m · 양옆 3.8m · 줄 사이 다리 공간 0.75m |
| 여백 | 스크린 앞 4.6m, 맨 뒷줄 뒤 3.0m |

배치는 `roomdef.js` 의 **`CINEMA`** 한 곳에서 바꿉니다 — 줄 수·좌석 수·간격·단 높이.

### 앉기 — 의자 앞에 서면 자동으로

의자마다 **앞쪽에 감지 구역**이 깔려 있습니다. 걸어가 몸이 의자에 닿으면
키를 누르지 않아도 **그대로 앉습니다**. 움직이거나 `Space` 를 누르면 일어섭니다.

| | |
|---|---|
| 자리 배정 | **서버가 쥡니다.** 두 사람이 같은 의자를 동시에 집으면 늦은 쪽이 `seatno` 로 거절됩니다 |
| 일어선 직후 | 구역을 **한 번 벗어나야** 다시 앉습니다 (일어서자마자 도로 앉는 일 방지) |
| 지나갈 때 | 줄 사이를 그냥 지나가려면 `Space` 로 **뛰어넘으면** 됩니다 |
| 새로고침 | 앉아 있던 의자까지 그대로 돌아옵니다 |
| 방을 뜨면 | 자리가 바로 풀립니다 (연결만 끊긴 경우엔 유예 30초 동안 맡아 둡니다) |

### 조명 — 전부 간접 조명

세워 두는 스탠드는 없습니다. 건축 조명만 씁니다.

- **천장 코브** — 벽에서 0.75m 안쪽, 천장 아래 0.3m 에 띠를 둘러 천장을 비춥니다.
  아래로 턱을 달아 광원이 직접 보이지 않고 천장만 밝아 보입니다
- **하단 간접** — 영화관 통로등처럼 벽 아래 10cm 높이를 따라 따뜻한 스트립이 깔립니다.
  소파 앉은 높이보다 낮아 눈에 직접 들어오지 않습니다

광원은 천장 4 + 하단 4 + TV + 전광판 + 네온 = 11개로 묶어 성능을 지킵니다.

밝기는 `roomdef.js` 의 **`LIGHT`** 한 곳에서 조절합니다 — 노출·환경광·코브·하단·화면·전광판.
영화관처럼 어둑하게 맞춰 두었고, **화면이 방에서 가장 밝은 것**이 되도록 했습니다.
좌석을 들인 뒤에도 바닥의 **73%** 를 걸어 다닐 수 있습니다.

TV 앞 자리와 뒤쪽 라운지로 구역이 나뉘고, 러그 2장이 각각을 덮습니다.
테이블 2개, 책장 2개, 화분 4개, TV 양옆 스피커.

## 유튜브가 어떻게 벽에 붙어 있나

유튜브 영상은 iframe 이라 **WebGL 텍스처로 가져올 수 없습니다.** (CORS·DRM)
그래서 두 겹으로 겹칩니다.

```
  ┌─ WebGL 캔버스 (위) ─ 투명 배경. TV 자리에만 '구멍'을 뚫는다
  │                      NoBlending 재질이 그 픽셀을 알파 0 으로 덮어씀
  └─ CSS3D 레이어 (아래) ─ 같은 카메라 행렬로 iframe 을 3D 변환
```

둘이 **같은 투영 행렬**을 쓰므로 비스듬히 봐도 원근이 정확히 맞습니다.
구멍 메시는 깊이 버퍼에도 쓰기 때문에, TV 앞을 지나가는 아바타는 화면을 제대로 가립니다.

픽셀 → 미터 환산도 정확히 맞췄습니다: iframe 1280×720px × 0.009375 = **12.0m × 6.75m**.

### 두 가지 시점

- **라운지 뷰** — 아바타에서 12.5m 떨어져 내려다보며 공전합니다 (휠로 조절). 천장과 남쪽 벽은
  안쪽에서만 보이는 면이라, 위에서 보면 **인형의 집처럼 방 안이 들여다보입니다.**
- **시청 모드 (1인칭)** — `V`. 눈높이 1.56m 로 내려가 TV 를 정면으로 봅니다.
  내 아바타는 숨고, 화면 가장자리가 어두워지며 TV 에 집중됩니다. 드래그로 둘러볼 수 있습니다.

### 점프와 가구

`Space` 로 **0.62m** 까지 뜹니다. 소파와 테이블 윗면이 0.45~0.46m 라 **올라서서 걸어 다닐 수 있고**,
책장(1.55m)·화분(1.1m)·스피커(1.05m)는 넘지 못해 그대로 장애물로 남습니다.
떠 있는 동안에는 발밑보다 낮은 가구를 통과하므로 걸려서 막히는 일이 줄어듭니다.

가구 충돌은 **회전까지 반영한 사각형(OBB)** 으로 봅니다. 외접 사각형으로 근사하면
비스듬한 의자 주변에 양옆 19cm 씩 보이지 않는 벽이 생겨 걸리적거립니다.
아바타 충돌 반지름도 0.32m → 0.26m 로 줄였습니다.

### 흡착 화살

고무컵이 달린 장난감 다트입니다. 쏜 사람이 **three.js 레이캐스트로 맞은 지점과 법선을 계산해
그대로 중계**하므로 모두의 화면에서 같은 자리에 꽂힙니다.
꽂히면 잠깐 떨다가 **5초 뒤 서서히 사라지고**, 사람에게 꽂히면 그 사람을 따라다닙니다.

## 방 코드와 초대

좌상단의 **입장 코드** 를 누르면 코드가 복사되고, **초대 링크 복사** 는
`주소/?r=코드` 형태의 링크를 복사합니다. 그 링크로 들어오면 코드가 자동으로 채워져
**입장** 만 누르면 됩니다.

왼쪽의 **인원 버튼** 을 누르면 지금 방에 있는 사람 목록이 펼쳐집니다 (기본은 접힘).
방장과 나에게는 각각 배지가 붙습니다.

## 방장

- **재생 / 정지, 이전 · 다음 영상** (하단 바)
- **방 제목 수정** — 좌상단 제목 옆 **✎**(또는 제목 글자)를 누르거나 **⚙ → 방 제목 수정**
- 하단 바의 재생목록 버튼으로 곡 추가·제거
- 방장이 나가면 **가장 오래 있던 사람에게 자동으로 넘어갑니다**

## 영상 동기화

서버는 `{몇 번째 영상, 재생중인가, 위치, 그 위치를 기록한 서버 시각}` 네 가지만 들고 있습니다.

1. 접속할 때 서버 시각을 같이 받아 **각자 시계를 보정**
2. 지금 있어야 할 위치 = `위치 + (지금 − 기록 시각)`
3. 실제 재생 위치가 **1.5초 이상 어긋나면 따라붙습니다** (1초마다 확인)
4. 방장은 5초마다 자기 실제 위치를 보내 흐른 만큼 보정

영상이 끝나면 자동으로 다음 곡. 마지막 다음은 처음으로 돌아옵니다.
브라우저가 소리 있는 자동재생을 막으면 음소거로 재생하며 **🔈 소리 켜기** 버튼을 띄웁니다.

## 구조

```
server.js              정적 서버 + WebSocket 룸 매니저 (의존성 0, RFC6455 직접 구현)
public/
  index.html           로비 · HUD · 모달 · importmap
  style.css            3D 레이어 + 유리질 UI
  roomdef.js           방 치수 · 가구 · 벽 배치 · 충돌  ← three.js 없이 순수 계산 (Node 에서 검증됨)
  scene3d.js           three.js 로 방을 짓는다 (재질 · 조명 · TV 구멍)
  avatar3d.js          둥근 카툰 2등신 — 캡슐 몸, 구 머리, 이름표/말풍선 스프라이트
  youtube.js           CSS3DObject + IFrame API + 재생 동기화
  game.js              카메라 두 모드 · 입력 · 네트워크 · 화살 · 전광판
  vendor/              three.module.js, CSS3DRenderer.js (동봉)
```

### 네트워크

- 10Hz 위치 브로드캐스트 (cm 단위 정수), 클라이언트에서 보간
- 방 하나 **정원 20명**, 동시 **최대 50개 방**
- 연결 전에 누른 버튼은 **큐에 담았다가** 열리면 전송
- 끊기면 2.5초마다 재연결하고 보던 방으로 **자동 재입장**
- 방이 비면 즉시 닫힘

### 서버가 막는 것

제어문자·방향 제어 문자 제거, 길이 제한(닉네임 12 / 방제목 40 / 채팅 120),
채팅 0.5초 · 화살 0.22초 쿨다운, 초당 120메시지 초과 시 연결 종료,
200KB 초과 프레임 거부, 정적 파일 경로 탈출 차단,
방장 아닌 사람의 재생·설정 조작 차단.

| 글자 | 캔버스에 그려 `MeshBasicMaterial` 로 붙입니다 — 방이 어두워도 **스스로 빛납니다** |

| 긴 제목 | 폭에 맞춰 글자를 88px → 46px 까지 줄이고, **그래도 넘치면 흐릅니다** (아래 참고) |
| 깜빡임 | 진짜 네온처럼 밝기가 미세하게 흔들립니다 |
| 벽 번짐 | 분홍 `PointLight` 하나가 스크린 위 벽을 물들입니다 (`LIGHT.neon`) |

### 간판보다 긴 제목 — 흐르게

46px 까지 줄여도 안 들어가면 말줄임 대신 **옆으로 흘립니다**. 흐를 거면 폭에
얽매일 이유가 없으므로 글자를 **76px 로 되키워** 읽기 좋게 둡니다.

| | |
|---|---|
| 속도 | 캔버스 기준 **100px/초** |
| 이음매 | 꼬리가 나가는 동안 머리가 들어오도록 **간격을 두고 두 벌 이상** 그립니다 |
| 양 끝 | `destination-out` 그라데이션으로 깎아 글자가 선에서 **뚝 끊기지 않습니다** |
| 비용 | 글자 폭은 곡이 바뀔 때 **한 번만** 재고, 다시 그리는 건 **20fps** 입니다 |

번호와 구분선은 흐르지 않습니다 — 자르는 창이 구분선 오른쪽에서 시작합니다.

제목이 빠진 만큼 **하단 컨트롤러도 40em → 27em 으로 좁혔습니다.**

## 상단 막대

왼쪽은 **방 제목**, 오른쪽은 **볼륨·자막** 묶음과 **세로 아이콘 열** 입니다.
좁아지면 줄바꿈 대신 제목이 `…` 로 줄어듭니다.

```
  방 제목                          [🔊 ━━━ CC]   ┌───┐
                                                │ ⎋ │  나가기
                                                │ ⚙ │  설정
                                                │ 👁 │  시점
                                                └───┘
```

아이콘을 가로로 늘어놓으면 제목이 들어갈 자리가 줄어듭니다. 세로로 쌓아 두면
제목은 넓게 쓰고, 메뉴는 열 **왼쪽**으로 펼쳐 아래 아이콘을 가리지 않습니다.

### ⚙ 설정 — 오른쪽 끝

버튼을 늘어놓는 대신 톱니바퀴 하나에 모았습니다. 누르면 아래로 펼쳐집니다.

| | |
|---|---|
| **방 제목 수정** | 제목이 입력칸으로 바뀝니다 (`Enter` 확정 · `Esc` 취소). **방장·부방장에게만 보입니다** — 좌상단 **✎ 또는 제목 글자**를 눌러도 같습니다 |
| **도움말** | `?` 키와 같은 창 |
| **공유** | **입장 코드**와 **초대 링크 복사** 가 같은 자리에 펼쳐집니다 |

코드나 링크를 누르면 복사되고 창은 접힙니다. 바깥을 눌러도 접힙니다.

### 👁 시점 — ⚙ 왼쪽

눈 아이콘입니다. **1인칭 · 3인칭 · 전체화면** 을 고릅니다.
글자가 없는 대신 지금 시점은 툴팁과 목록의 강조로 알리고,
3인칭이 아닐 때는 아이콘이 켜집니다.

## 컨트롤러 — 중앙 위

재생 버튼과 진행 막대는 **화면 맨 위 가운데에 여백 없이 붙어** 있습니다.
화면 아래쪽을 채팅에 내주고, 조작은 시선이 머무는 스크린 가까이로 올렸습니다.

아래쪽으로 **작은 탭**이 하나 튀어나와 있습니다. 누르면 컨트롤러가 **통째로 위로**
빠지고 **탭만** 화면 맨 위에 남습니다. 탭이 패널 **바깥**에 붙어 있어서,
패널을 꼭 `-100%` 만 올리면 탭이 정확히 화면 맨 위에 걸립니다.
접어 둔 상태는 탭에 기억해 새로고침해도 유지됩니다.

상단 막대는 **가운데 칸을 컨트롤러 몫으로 비워 둔 3단 격자**라, 천장에 붙여도
제목과 겹치지 않습니다. 창이 좁아져도 **줄을 바꾸거나 숨기지 않고**, 컨트롤러처럼
**전부 같은 비율로 줄어듭니다** — 가운데 칸이 `--ctl-w` 를 따라 좁아지는 만큼
양옆 칸도 함께 좁아지기 때문입니다.

### 반응형 — 기준값 네 개

`style.css` 의 `:root` 에 모아 두었습니다. 상단 UI 는 전부 이 값을 따라 움직입니다.

| 변수 | 뜻 |
|---|---|
| `--ui-fs` | **HUD 전체 기준 글자** `clamp(9px, 0.95vw, 13px)` — 아이콘·제목·볼륨 묶음이 전부 이 em |
| `--ctl-fs` | 컨트롤러 기준 글자 `clamp(8px, 1.05vw, 14px)` |
| `--ctl-w` | 컨트롤러 폭 `27 × --ctl-fs` — 상단 막대 가운데 칸이 이 폭 |
| `--ctl-h` | 컨트롤러 높이 — 토스트가 이만큼 내려온다 |
| `--title-h` | 아이콘 한 칸 = 제목 줄 높이 `--ui-fs × 2.62` |
| `--iconcol-h` | 아이콘 열 전체 높이 — 재생목록 패널이 이만큼 내려온다 |

아이콘은 `34px` 같은 고정값이 아니라 `2.62em` 이고, 안쪽 SVG 까지 `1.31em` 이라
창을 줄이면 테두리·둥근 모서리·그림이 **한 덩어리로** 작아집니다.
볼륨·자막 묶음도 숨기지 않고 같이 줄어듭니다 (**500px** 아래에서만 볼륨 막대를 접습니다).

참여자 패널은 폭 `clamp(176px, 19vw, 260px)`, 글자 `clamp(11.5px, 0.92vw, 13px)`,
채팅은 폭 `clamp(300px, 40vw, 540px)`, 글자 `clamp(11.5px, 0.95vw, 13px)` 로 함께 줄고 늡니다.
접힘 높이는 글자에서 계산하므로 **글자가 줄어도 정확히 두 줄**입니다.

## 채팅 — 중앙 하단

```
                        ┌──⌄──┐             ← 튀어나온 탭만 눌러 접기 / 펼치기
           ┌────────────┴─────┴──────────┐
           │ 지난 내역                    │
           ├─────────────────────────────┤
           │ 메시지를 입력하세요 (Enter) ➤ │  ← 늘 보인다
           └─────────────────────────────┘
```

| | |
|---|---|
| 접음 (기본) | 내역이 **최근 2줄**(63px)만 남습니다. **입력칸은 그대로** 보입니다 |
| 펼침 | 내역이 **168px** 로 늘어나고 넘치면 스크롤합니다 |
| 어느 쪽이든 | 새 메시지가 오면 맨 아래로 따라붙습니다 |

입력칸 오른쪽의 **➤** 는 `Enter` 를 대신합니다. 키보드가 없는 기기를 위한 것이라
폰에서는 버튼이 커지고(46×42) 입력 글자도 16px 로 올라갑니다 — iOS 가 16px 미만
입력칸에 포커스가 가면 화면을 확대해 버리기 때문입니다.
`Enter` 로 보내면 입력칸을 놓아 바로 조작으로 돌아가고, **➤ 로 보내면 포커스를 지켜**
키보드가 내려가지 않습니다.

머리말 줄은 두지 않았습니다. 패널 위로 **튀어나온 작은 탭**(54px) 하나가
접기·펴기 전부이고, 글자를 바꾸는 대신 180° 돌려 `⌄` ↔ `⌃` 가 됩니다.
가로를 가득 채우지 않아 패널 윗변이 깔끔하게 남습니다.

올려서 지난 내역을 읽는 중에는 끌어내리지 않고, 그 동안 온 메시지 수를
화살표 오른쪽에 배지로 띄웁니다. 맨 아래로 돌아오면 배지가 사라집니다.

## 참여자 패널 — 왼쪽

기본으로 **펼쳐져** 있습니다. 접어 두어도 머리말만으로 누가 있는지 보입니다.

```
┌────────────────────────────────┐
│ ▾  참여자  ●●●●○       4 /20   │   ← ○ 는 연결이 끊긴 사람
└────────────────────────────────┘
```

| | |
|---|---|
| 색 점 | 사람마다 하나. 아바타 색과 같습니다 (9명까지, 넘으면 `+n`) |
| 인원 변화 | 들어오거나 나가면 테두리가 **잠깐 반짝입니다** |
| 접힘 여부 | 탭에 기억해 두어 새로고침해도 유지됩니다 |

펼치면 이름·방장/부방장 배지·연결 끊김 표시가 나옵니다.

### 내 이름 — 줄 오른쪽 ✎

내 줄에만 **✎** 가 붙습니다. 누르면 이름이 입력칸으로 바뀌고 `Enter` 로 확정, `Esc` 로 취소합니다.
같은 방에 이미 쓰는 사람이 있는 이름은 거절됩니다. 바꾼 이름은 머리 위 이름표와
명단에 바로 반영되고, 새로고침해도 유지됩니다.

### 사람 관리 — 줄 오른쪽 ⋯

방장에게만, 자기 아닌 사람 줄 오른쪽에 **⋯** 가 보입니다. 누르면 메뉴가 뜹니다.

| | |
|---|---|
| **부방장 지정 / 해제** | 재생·설정을 함께 만질 수 있게 합니다 |
| **방장 넘기기** | 확인을 거쳐 방장을 넘깁니다 |
| **내보내기** | 확인을 거쳐 방에서 내보냅니다 |

목록 상자가 `overflow:auto` 라 그 안에 드롭다운을 넣으면 잘립니다.
메뉴는 **하나만 만들어 목록 바깥에 두고**(`position:fixed`) 누른 ⋯ 아래로 옮겨 띄웁니다.
화면 밖으로 넘칠 자리면 위쪽으로 붙습니다.

### 내보내기

방장만 할 수 있습니다. 부방장도 못 합니다.

- 내보내진 사람은 **로비로 돌아가고** 보관해 둔 자리를 버립니다 (새로고침해도 다시 끌려오지 않습니다)
- 앉아 있던 **의자가 즉시 풀립니다**
- 같은 창(재입장 토큰)으로는 **5분간**(`KICK_BAN_MS`) 다시 못 들어옵니다
- 남은 사람에게는 "○○ 님을 내보냈습니다" 가 뜹니다

> 창을 새로 열면 토큰이 새로 발급되므로 코드만 알면 다시 들어올 수 있습니다.
> 완전히 막으려면 계정이 필요합니다.

## 새로고침 · 끊김 복구

새로고침하거나 잠깐 네트워크가 끊겨도 방에서 튕기지 않습니다.

입장할 때 서버가 **재입장 토큰**을 내주고, 브라우저는 방 코드·닉네임과 함께
`sessionStorage` 에 넣어 둡니다. 탭을 닫으면 사라지고 다른 탭에 새지도 않습니다.

소켓이 끊기면 서버는 바로 내보내지 않고 **30초**(`GRACE_MS`) 동안 자리를 지켜 둡니다.

| 그 사이 | |
|---|---|
| 끊긴 사람 | 아바타가 **반투명**해지고 명단에 **연결 끊김** 이 붙습니다 |
| 자리 | 같은 id·**방장/부방장 권한까지** 그대로 남습니다 |
| 방 | 혼자 있던 방이어도 닫히지 않습니다 (로비 목록에서만 감춰집니다) |
| 정원 | 유예 중인 사람도 한 자리를 차지합니다 |

30초 안에 같은 토큰으로 돌아오면 **있던 자리 그대로** 복구되고, 로비를 거치지 않습니다.
넘기면 그때 정식 퇴장 처리되어 방장이 넘어가고 빈 방은 닫힙니다.

**나가기** 버튼으로 직접 나간 경우는 토큰을 버리므로 다음 접속 때 로비로 갑니다.
